Le Relais DOTR · espace équipe

Cette page prépare les codes d'accès et le fichier acces.json. Tout se passe dans votre navigateur : rien n'est envoyé nulle part, sauf un contrôle du jeton auprès de GitHub.

1 · Créer le jeton d'accès sur GitHub

  1. Sur github.com : votre photo ▸ Settings ▸ Developer settings ▸ Personal access tokens ▸ Fine-grained tokens ▸ Generate new token.
  2. Nom : Relais DOTR. Durée : la plus longue possible (notez la date, il faudra le renouveler).
  3. Repository access ▸ Only select repositories ▸ choisissez uniquement le dépôt du site.
  4. Permissions ▸ Repository permissions ▸ Contents : Read and write (rien d'autre).
  5. Générez, puis copiez le jeton (commence par github_pat_).

4 · Déposer le fichier

  1. Cliquez sur Télécharger acces.json.
  2. Sur GitHub, dans le dossier data du dépôt : Add file ▸ Upload files, déposez-le (il remplace l'ancien) puis Commit changes.
  3. Attendez 1 à 3 minutes : les boutons « Ajouter un document » fonctionnent.
